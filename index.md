📄 Privacy Policy (English Version)
Last Updated: November18, 2025
Operator: Masayoshi Tomita
1. Information We Collect
This application (“the App”) may collect the following information within the necessary scope.
(1) Voice Data
When you use the translation function, microphone input is processed for speech recognition.
Voice data is processed in real time and is not stored on any server.
In some cases, processing may occur on the device locally.
(2) Translated Text
Translation results may be saved on your device as conversation logs (which you can delete at any time).
These logs are never sent to external servers.
(3) App Usage Information
To improve the App, crash logs and basic usage statistics may be collected.
These do not include any information that identifies an individual user.
2. Purpose of Use
The collected information is used solely for the following purposes:
Providing speech recognition and translation features
Improving app quality and fixing bugs
User support
3. Provision of Data to Third Parties
The App does not provide user information to third parties except in the following cases:
When required by law
When the user grants consent
When external services are required to provide app functions within the minimum necessary scope
(Examples: Apple Speech, OpenAI API, etc. — clearly stated if used)
4. Data Retention
Conversation logs are saved only on the user’s device and can be deleted at any time by the user.
The App does not store any data on external servers.
5. User Rights
Users have the following rights:
View saved logs
Delete logs
Stop using the App and uninstall it
6. Security
User data is protected through the following measures:
Voice data is discarded immediately after real-time processing
Locally stored data follows the security standards of the operating system
All external communications are encrypted (HTTPS)

1. 収集する情報
本アプリでは、以下の情報を必要な範囲で収集する場合があります。
（1）音声データ
翻訳機能を利用する際、音声認識のためマイク入力を処理します。
音声データはリアルタイムで処理され、サーバーに保存されません。
端末内で処理される場合があります。
（2）翻訳テキスト
翻訳結果のテキストを会話ログとして端末内に保存します（ユーザー操作で削除可能）。
外部サーバーへ送信されることはありません。
（3）アプリの利用状況
改善のため、クラッシュログや利用統計を収集する場合があります。
個人が特定される情報は含まれません。
2. 情報の利用目的
収集した情報は以下の目的のために利用します。
音声認識・翻訳機能の提供
アプリの品質向上・バグ修正
ユーザーサポート
3. 第三者提供について
当アプリは、以下の場合を除き、情報を第三者へ提供することはありません。
法令に基づく場合
ユーザーの同意を得た場合
翻訳エンジンなど機能提供のために必要な最小限の範囲で外部サービスを使用する場合
（※外部サービス例：Apple Speech、OpenAI API など
使用している場合は明記します）
4. データの保存期間
会話ログはユーザーの端末内に保存され、ユーザーによっていつでも削除できます。
